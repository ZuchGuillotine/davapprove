    What this does

    Enter a parcel and a project type. The assistant reads the public map layers that regulators use, then tells you:

    • Which agencies the project will route through, and why, with the code section behind each one.
    • What to add to the bid for permit fees and studies, as a low to high range with a source for every line.
    • Where the lot is constrained by mapped critical areas, buffers, shoreline and flood zones.
    • What has been permitted before on the parcel, and what has lapsed.

    This is a screening tool for early client conversations. It reads maps and code; it does not replace a site visit, a delineation, a survey or an agency determination.
